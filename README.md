# Автоцентр Южный — сайт шиномонтажа

Одностраничный сайт автоцентра «Южный» в Кемерово: шиномонтаж, балансировка, мойка, зона отдыха для клиентов, контакты и карта проезда.

- Адрес: г. Кемерово, ул. Радищева, 1Г
- Телефон: +7 3842 76-74-74
- Режим работы: ежедневно с 10:00 до 22:00

## Технологии
React 19, TypeScript, TanStack Start (серверный рендеринг), Vite, Tailwind CSS, shadcn/ui.

## Запуск
    bun install
    bun run dev
Сайт откроется на http://localhost:5173

## Где что менять
Телефон, адрес, часы работы и фото — в файле src/components/site/data.ts.
